# 源声视界 · 听音室 3D 交付页面

这是已完成的交互式听音室页面，支持自由观察、漫游、距离标注、产品查看、界面最大化、侧栏折叠和文字隐藏。

## 本地打开

用桌面浏览器打开 `index.html`。模型、产品参考图片、场景照片和脚本均已内嵌，不需要安装依赖。

## 发布到 GitHub Pages

1. 创建独立的公开仓库，建议名称 `ysv-listening-room`。
2. 解压本压缩包，将 `index.html`、`.nojekyll`、`README.md` 上传到仓库 `main` 分支根目录。请上传解压后的文件，而不是 ZIP 文件本身。
3. 打开仓库 **Settings → Pages**。
4. 在 **Build and deployment → Source** 选择 **Deploy from a branch**。
5. Branch 选择 **main**，文件夹选择 **/(root)**，点击 **Save**。
6. 部署完成后使用 Pages 页面显示的 **Visit site** 地址；仓库文件预览地址不是交互页面地址。

发布设置参考：[GitHub 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 本版已确认的定位

- 房间净尺寸：宽 4.72 m，深 6.548 m，高 3 m。
- 音箱外侧边距侧墙 1 m；前障板距前墙 1 m；去除音箱网罩。
- 皇帝位 3.61 m 指坐下后耳朵到前墙的距离，不是沙发中心。
- 沙发与书桌已同步前移约 0.50 m。
- 前墙共 4 块模块；左墙 3 块模块已前移 0.30 m，并在墙面高度方向居中。
- 前墙两角低频陷阱壁挂，高度方向居中：离地 0.60 m，顶部 2.40 m。
- 右侧声学画向后墙移动，保留窗户。

声学模块使用既定交付配置。房间和产品外观依照上传照片建模，未实测的家具和局部尺寸为示意，不作为施工放样依据。
