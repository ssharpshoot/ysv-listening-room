## JBL 9.4.6 影院方案

当前交付版为 **V13.1**，包含方案汇报与自由漫游两个入口。

- **空间规划**：房间尺寸、两排座位、幕布位置，以及各座位与设备的关系。
- **画面体验**：180英寸幕布的逐座水平视角、观看仰角及理论亮度。
- **声音系统**：主声道、增宽、环绕、顶部和四只低音炮的布局与分组演示。
- **影院与 KTV**：设备分工、共享低频、信号链和场景切换逻辑。
- **声学与完成面**：吸声、扩散、低频控制与室内装修的配合。
- **交付说明**：设备清单、测量调试与验收内容。

支持客户、声学、工程三种查看模式，以及拖动观察、座位选择、演示重播、最大化和说明栏折叠等操作。

V13.1 在 V13 功能基础上修复了慢加载被固定超时判定为永久错误的问题。**旧设备的实际运行情况仍需按系统、浏览器及图形能力检查，不能仅凭版本号保证兼容。**

## HiFi 听音室方案

听音室页面与影院项目独立维护。当前方案围绕 **宽4.72 m × 长6.548 m × 高3.00 m** 的空间，展示音箱、听音位、家具与声学模块的关系。

可查看空间布局、距离标注、产品参考和声学布置，并通过最大化、折叠说明及隐藏文字调整演示界面。

## 数据与图形说明

页面中的**设计目标、理论估算、模拟和现场实测**应分别理解。声压、亮度及房间共振等计算用于说明方案依据，不能直接替代现场测量或逐频验收。
