# 客户汇报与选型逻辑

## 汇报主线

按客户实际问题选择页面数量，不固定为JBL案例的26页：

1. 您希望怎样使用：电影、音乐、KTV、家人和来客，预算与优先级。
2. 房间怎么安排：有效空间、幕布、座位、通道、门窗、设备检修和安装约束。
3. 坐在这里得到什么：逐座画面大小、声音覆盖及两排差异。
4. 为什么这样选产品：需要的能力、候选比较、安装和驱动条件。
5. 声学与装修怎样配合：室内声音、隔声目标、完成面、通风噪声和舒适。
6. 整体多少钱：设备、工程和服务，包含/不包含，可选升级与节省项。
7. 平时怎么用：开关机、电影/KTV切换、家人操作和维护。
8. 怎样证明交付效果：测点、报告、操作指南、验收和售后安排。

客户已经明确最关心某些问题时调整顺序，不把技术演示页机械前置。

## 个人专业性

采用“设计师判断 → 可见依据 → 客户收益”的短句。
例如：“第二排距离更远，所以我们同时核查两排的输出余量，避免只照顾前排。”
凭真实图纸、条件明确的计算、现场测量、可执行的安装与验收说明建立信任。
使用真实身份、证书、照片、案例；证书背景不等于当前项目已获认证。

## 产品选择比较

至少比较推荐方案与一个合理替代；如果替代资料缺失，列待补条件。
比较房间距离、覆盖、可用输出、频带、负载/驱动、箱体/安装、国内供应和售后、总成本。
不要仅比较单个最大功率数字；不要虚构竞争型号短板。
选型结论可用推荐 / 有条件推荐 / 不推荐 / 信息不足，并用一两句话说明条件。
说明升级增加的收益、费用与安装代价，避免声称价格越高每个座位效果就越好。

## 预算与服务

列设备、声学/隔声、装修、安装调试、控制、运输税费、维护与未包含项。
预算总额以有效报价为准；缺价用“待报价”，不以0元凑总价。
说明设备供应、声学施工、装修配合和调试的责任；项目日期、工期、售后条件需真实输入。
内部风险放工程记录；客户正文保留影响决策的适用条件，避免大量无助于选择的批注。

## 文案约定

- 每页先一句客户能理解的结论，再2—4条理由或一个紧凑结果表。
- 技术详情折叠，数字配单位，中文为主；专业术语首次用中文（English）。
- 保留已批准文字，删除已要求删除的重复批注；计算身份标签仍必须准确。
- “每个座位皇帝位”“超过电影院”等作为用户愿景时不转成无条件验收承诺。
- 不同座位的实际差异应如实说明，并解释设计与调试如何缩小差异。

## 视频交接边界

本技能可输出页面与镜头素材映射、项目参数及口播要点。
获客短视频和客户完整汇报的结构不同，应分别规划。
实际配音、时间轴、字幕、渲染与成片验收交给专门的视频流程；不要仅有脚本便称视频制作完成。
