# 当前影院项目执行规则

填写项目ID与范围；有同名文件时合并。不要把本模板未经填写当实际工程规则。

## 开始

先读适用父级AGENTS.md、当前MEMORY.md、项目数据、真实入口和用户最新要求。
确认同一项目、实际分支、工作树与版本；保留用户改动。
使用 $ysv-cinema-proposal 时按需读其参考资料，不导入其他项目参数。

## 执行边界

按本次授权完成；用户明确先审阅时输出需求表，等待后再做依赖修改。
已授权的常规排版、检查和可逆修复持续完成。
新建项目：独立目录/ID/路径。当前项目的锁定几何与发布范围见MEMORY.md。

## 工程与客户材料

保留已确认坐标、朝向、声道左右与尺寸；显示变化不能移动工程对象。
区分理论估算、模拟和实测，关键数值配单位和来源。
客户正文解释设计价值，技术条件按需展开，不能编造型号对比、报价和验收结果。
专业术语首次使用中文（English）；数值块不换行，正文正常换行。

## 验证与交付

按风险检查受影响计算、布局、交互或部署，记录真实执行环境和未测项。
用户明确发布授权及目标后执行；不能沿用其他项目授权。
输出成果、差异、检查、剩余问题，更新MEMORY.md；不记录凭证。
